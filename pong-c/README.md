# PONG 🏓 — Си + PDCurses (ncurses-API)

Классический Pong 1972 года по мотивам [ponggame.org](https://www.ponggame.org/).
Написан на чистом Си, отрисован через PDCurses (тот же API, что ncurses, но для Windows).

## Играть

Запусти **Pong.exe** (или я запущу его тебе). Играется в консольном окне.

| Клавиша | Действие |
|---|---|
| `W` / `S` | Левая ракетка вверх/вниз |
| `↑` / `↓` | Правая ракетка (в режиме на двоих) |
| `1` | Игра против ИИ |
| `2` | Игра вдвоём |
| `R` | Реванш |
| `M` | Меню |
| `Q` | Выход |

Правила классические: первый до **11 очков**. Мяч ускоряется с каждым ударом
ракеткой, угол отскока зависит от точки попадания и движения ракетки.

## Что внутри

- `pong.c` — вся игра, ~250 строк чистого Си
- `Pong.exe` — готовая сборка (189 КБ), статически слинкована с PDCurses

## Собрать самому

Понадобится любой C-компилятор и исходники [PDCurses](https://github.com/wmcbrine/PDCurses):

```sh
zig cc -O2 -std=c99 -o Pong.exe pong.c pdcurses/*.c wincon/*.c \
    -I. -Iwincon -luser32 -lgdi32 -lwinmm
```

(также подойдёт gcc из MinGW или MSYS2: `gcc -O2 -o Pong.exe ...`)

## ИИ-противник

Следит за мячом с ограниченной скоростью (0.62 клетки/кадр против твоей 1.0)
и раз в ~0.3 секунды «переоценивает» мяч с маленькой ошибкой — поэтому его
можно обыграть финтами по краю ракетки.
